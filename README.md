# OpenModelica Simulation Runner- PyQt6 Desktop Application 

**OpenModelica Simulation Runner** is a lightweight desktop application built with **Python and PyQt6** for executing an OpenModelica-generated simulation executable with user-defined simulation parameters.

The application provides a simple graphical interface where users can select an OpenModelica executable, specify the simulation start and stop times, validate the inputs, execute the simulation, and view the simulation output directly inside the application.

## Overview

The project consists of two main components:

1. An **OpenModelica simulation model** based on the `TwoConnectedTanks` model.
2. A **Python/PyQt6 desktop application** that executes the generated simulation executable with user-provided start and stop times.

The application communicates with the OpenModelica executable through Python's `subprocess` module.

> **Objective:** Provide a simple and user-friendly desktop interface for executing an OpenModelica simulation without requiring the user to interact with the OpenModelica command line directly.

## Object-Oriented Design

The application follows an object-oriented structure with separate classes for GUI management and simulation execution.

### `SimulationApp`

The `SimulationApp` class is responsible for:

- Creating and managing the PyQt6 graphical interface
- Handling user input
- Validating simulation parameters
- Starting the simulation
- Displaying simulation status
- Displaying simulation output

### `SimulationRunner`

The `SimulationRunner` class is responsible for:

- Preparing the OpenModelica execution command
- Configuring the required runtime environment
- Executing the simulation using Python's `subprocess` module
- Capturing standard output and error output
- Returning the simulation result to the GUI

## Installation & Setup

### Prerequisites

Before running the application, install:

- Python 3.6+
- PyQt6
- OpenModelica
- Windows 10/11

### Clone the Repository

    git clone https://github.com/dishadhikari/fossee
    cd fossee

### Install Dependencies

    pip install -r requirements.txt

### Run the Application

    python app.py

The PyQt6 desktop application will open.

### Select the OpenModelica Executable

Use the **Browse** button in the application to select the compiled:

    TwoConnectedTanks.exe

The executable is generated by compiling the `TwoConnectedTanks` model in OpenModelica.

### Run the Simulation

1. Select `TwoConnectedTanks.exe`.
2. Enter the **Start Time**.
3. Enter the **Stop Time**.
4. Click **Run Simulation**.
5. The application executes the OpenModelica program.
6. The simulation status and output are displayed in the GUI.


## OOPs Design and Concepts Used

The application uses Object-Oriented Programming concepts through Python and PyQt6.

### Encapsulation

The GUI components and application state are maintained inside the main application class.

    class SimulationApp(QMainWindow):
        ...

For example:

    self.application_input
    self.start_time_input
    self.stop_time_input
    self.run_button

This keeps the application's data and behavior organized within the class.

### Inheritance
The application class inherits from `QMainWindow` provided by PyQt6.

    class SimulationApp(QMainWindow):

This allows the application to use the functionality of the PyQt6 window framework while adding custom simulation functionality.

### Abstraction
The user does not need to manually open a terminal or construct the OpenModelica command.
The user simply:

    Select Executable
          ↓
    Enter Start Time
          ↓
    Enter Stop Time
          ↓
    Run Simulation

The application handles command construction and execution internally.

### Modularity
Different application responsibilities are implemented through separate methods.
Examples include:

    select_application()
    validate_inputs()
    run_simulation()
This makes the code easier to maintain, debug, and extend.

### Reusability
The application can be used repeatedly with different simulation parameters without modifying the source code.

## Input Validation

The application validates the simulation parameters before starting the OpenModelica process.
The screening task requires:

    0 <= start time < stop time < 5

### Valid Example

    Start Time: 0
    Stop Time: 1

This satisfies:

    0 <= 0 < 1 < 5

### Invalid Example 

    Start Time: 2
    Stop Time: 1

This is invalid because:

    start time >= stop time

### Validation Checks

The application checks that:

- An executable has been selected.
- The executable exists.
- Start time is an integer.
- Stop time is an integer.
- Start time is non-negative.
- Stop time is greater than start time.
- Stop time is less than `5`.

If the input is invalid, the application displays an error message and does not start the simulation.


## OpenModelica Model

The application uses the `TwoConnectedTanks` model provided for the OpenModelica screening task.

### Model Structure

    NonInteractingTanks
    │
    ├── Tank
    ├── Tank2
    ├── FlowConnect
    └── TwoConnectedTanks

### FlowConnect

`FlowConnect` is a custom Modelica connector used to transfer the flow variable between the two tank models.

    within NonInteractingTanks;

    connector FlowConnect
      Real F;
    end FlowConnect;

### Tank

`Tank` represents the first tank.

It defines the inlet flow, outlet flow, tank level, and connection to the second tank.

### Tank2

`Tank2` represents the second tank and receives flow from `Tank` through the `FlowConnect` connector.

### TwoConnectedTanks

`TwoConnectedTanks` combines the two tanks and connects them using the custom connector.

The model is compiled using OpenModelica to generate:

    TwoConnectedTanks.exe

The Python application executes this generated executable using Python's `subprocess` module.

OpenModelica may produce output similar to:

    LOG_SUCCESS | info | The initialization finished successfully.

    LOG_SUCCESS | info | The simulation finished successfully.

A return code of:

    0

indicates that the simulation process completed successfully.

### Example Validation Error

If the user enters:

    Start Time: 3
    Stop Time: 2

the application does not start the simulation and displays:

    Error:
    Start time must be less than stop time.
